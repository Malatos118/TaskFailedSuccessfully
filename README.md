# Task Flow

Application minimale, rapide et élégante de gestion de tâches par profils d'espaces.

## Fonctionnalités

- **Profils d'espaces** : basculez entre plusieurs contextes étanches (`💼 Pro`, `🎓 Étudiant`, `🏠 Perso`) ou créez-en de nouveaux (`+ Nouveau...`). Chaque profil conserve ses propres tâches et son état.
- **Priorités** : 🔴 Haute, 🟡 Moyenne et 🟢 Basse avec tri automatique (urgences en tête) et alternance en 1 clic.
- **Filtres avec compteurs** : visualisez en direct le nombre de tâches par niveau.
- **Gestion rapide** : ajout en 1 touche (Entrée), validation barrée, suppression `×` et nettoyage des terminées.
- **Persistance** : sauvegarde automatique de tous les profils dans le `localStorage`.

## Démarrage

Ouvrez simplement `index.html` dans votre navigateur.
